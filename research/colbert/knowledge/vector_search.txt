HNSW (Hierarchical Navigable Small World) is an approximate nearest neighbor search algorithm that builds a multi-layered graph. The bottom layer contains all nodes; each higher layer contains a geometrically decreasing subset of nodes. Search starts at the top layer with greedy traversal, then descends layer by layer, using each layer's result as the entry point for the next. The algorithm achieves O(log N) search complexity with high recall. Key parameters are M (max edges per node) and ef (beam width during search).

Cosine similarity measures the angle between two vectors, defined as cos(theta) = (A dot B) / (|A| * |B|). Values range from -1 (opposite) to +1 (identical direction). For unit-normalized vectors, cosine similarity equals the dot product. It is widely used in text retrieval and semantic search because it is invariant to vector magnitude — a property that helps when comparing embeddings from different-length texts. For int8 quantized vectors without normalization, the raw dot product is a reasonable proxy for cosine similarity.

Approximate nearest neighbor (ANN) search trades exact results for speed. Instead of comparing a query against every vector in the database (brute-force, O(N)), ANN algorithms use indexing structures to find near-optimal results in O(log N) or O(1) amortized time. Common approaches include tree-based methods (KD-trees, ball trees), hash-based methods (locality-sensitive hashing), and graph-based methods (HNSW, NSW, DiskANN). Graph-based methods currently dominate benchmarks for high-dimensional vectors due to their adaptability to data distribution.

ColBERT (Contextualized Late Interaction over BERT) is a neural retrieval model that produces token-level embeddings instead of a single vector per document. For a query with Q tokens and a document with D tokens, ColBERT computes MaxSim: for each query token, find the maximum cosine similarity with any document token, then sum across query tokens. This preserves fine-grained token-level matching while allowing precomputation of document embeddings. ColBERT typically outperforms single-vector models on retrieval benchmarks by 5-15% MAP.

Product quantization (PQ) is a compression technique for vectors used in approximate nearest neighbor search. It splits each vector into sub-vectors (e.g., 8 sub-vectors of 16 dimensions each), independently quantizes each sub-vector to one of 256 centroids (learned via k-means), and stores only the centroid indices (1 byte each). This reduces a 128-dimensional float32 vector from 512 bytes to just 8 bytes — a 64x compression. Distance computation uses precomputed lookup tables. PQ is used by FAISS and other large-scale vector search libraries.

Embedding models convert text, images, or other data into fixed-dimensional vectors (embeddings) that capture semantic meaning. Text embedding models like sentence transformers map sentences to vectors where semantically similar texts have high cosine similarity. The embedding dimension varies by model: common sizes are 384 (MiniLM), 768 (BERT-base), 1024 (LFM2-350M), and 1536 (OpenAI text-embedding-3-small). Higher dimensions capture more nuance but require more storage and compute for similarity search.

Retrieval-augmented generation (RAG) combines information retrieval with language model generation. Instead of relying solely on the model's parametric knowledge, RAG first retrieves relevant documents from an external knowledge base, then includes the retrieved text in the LLM prompt as context. This reduces hallucination, allows updating knowledge without retraining, and provides attribution for generated claims. The quality of RAG depends heavily on retrieval quality — irrelevant documents in the context can actually hurt generation quality compared to no retrieval.

Late interaction in ColBERT refers to the scoring mechanism where query and document token embeddings are computed independently but interact during scoring via MaxSim. This enables offline document embedding (compute once, store forever) while maintaining token-level matching precision. In contrast, cross-encoders process query and document together through the full transformer (highest quality but slowest), while bi-encoders produce single vectors per query and document (fastest but lower quality). ColBERT occupies the sweet spot: near cross-encoder quality with bi-encoder-like precomputation.

Inverted file index (IVF) partitions the vector space into Voronoi cells using k-means clustering. At query time, only vectors in the nearest cells are searched, reducing the search space by a factor proportional to the number of cells divided by the number of probes. IVF can be combined with product quantization (IVF-PQ) for both speed and compression. For million-scale datasets, IVF with 4096 cells and 32 probes typically achieves 95%+ recall at 10-100x speedup over brute force.

Scalar quantization for vector search converts floating-point vectors to lower precision (int8, int4) with minimal quality loss. For int8, each dimension is independently mapped to [-128, 127] using per-vector or per-dimension min/max scaling. This reduces storage by 4x compared to float32 and enables integer SIMD instructions (like ARM SDOT) for distance computation. Research shows int8 quantization preserves 99%+ of ranking quality for most embedding models, making it the default choice for on-device vector search where memory is constrained.
