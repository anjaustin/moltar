ARM Cortex-A78 is a high-performance CPU core designed by ARM Holdings, released in 2020. It uses the ARMv8.2-a instruction set architecture and is typically manufactured at 5nm or 7nm process nodes. The A78 achieves approximately 20% better sustained performance compared to the Cortex-A77 while consuming similar power. It features a 4-wide decode pipeline, 8-issue out-of-order execution engine, and supports branch prediction with a 64KB L1 instruction cache and 64KB L1 data cache per core.

ARM Cortex-A55 is an efficiency core designed for low-power operation. It implements the ARMv8.2-a ISA but uses a simpler in-order pipeline with dual-issue execution. The A55 consumes roughly one-quarter the power of an A78 at the same frequency but delivers about one-third the performance. In big.LITTLE configurations, A55 cores handle background tasks and light workloads while A78 cores handle compute-intensive work.

The ARMv8.2-a instruction set includes the NEON SIMD extension with 128-bit vector registers (v0 through v31). Key instructions for machine learning include SDOT and UDOT (dot product), which compute four 8-bit multiplications and accumulate into 32-bit results in a single instruction. The SDOT instruction processes signed int8 values and is critical for quantized neural network inference, providing roughly 4x throughput over scalar multiply-accumulate for int8 workloads.

LPDDR4X is a low-power double data rate memory standard used in mobile devices. At 4266MHz, a single 32-bit channel provides approximately 8.5 GB/s of bandwidth. Dual-channel configurations double this to about 17 GB/s theoretical, though sustained bandwidth on mobile devices is typically 85-90% of theoretical due to refresh cycles and bank conflicts. LPDDR4X reduces I/O voltage from 1.1V (LPDDR4) to 0.6V, cutting I/O power consumption by roughly 20%.

Cache hierarchy on modern ARM processors follows a three-level design. L1 caches (instruction and data) are private per core with 1-2 cycle latency and typically 32KB or 64KB each. L2 caches are private per core on A78 (256KB) with approximately 8-10 cycle latency. L3 cache (DSU - DynamIQ Shared Unit) is shared across all cores, typically 1-4MB, with 20-30 cycle latency. Cache line size is universally 64 bytes on ARMv8. Memory access patterns that respect cache line boundaries and avoid false sharing between cores are critical for performance.

The DynamIQ Shared Unit (DSU) manages the L3 cache and inter-core communication in ARM big.LITTLE processors. It supports heterogeneous core configurations like 2+6 (2 big + 6 little) with coherent cache access across all cores. The DSU implements a snoop filter to reduce inter-core cache coherence traffic. On MediaTek Dimensity 930, the DSU provides approximately 1MB of shared L3 cache accessible by both A78 and A55 cores.

NEON vector processing handles multiple data elements simultaneously using 128-bit registers. For int8 operations, each NEON register holds 16 elements. The SDOT instruction computes dot products of four int8 pairs per lane, accumulating into four int32 lanes — processing 16 multiply-accumulate operations in a single cycle. For 48-dimensional int8 vectors (as used in LCVDB), three SMULL/SADALP operations across 16-element chunks complete the full dot product in approximately 12 cycles on Cortex-A78.

MediaTek Dimensity 930 is a mid-range mobile SoC fabricated on TSMC 6nm process. It combines 2x Cortex-A78 at 2.2GHz with 6x Cortex-A55 at 2.0GHz in a big.LITTLE configuration. The integrated GPU is PowerVR BXM-8-256 supporting OpenCL 3.0. It includes a 5G modem, ISP for dual cameras, and AI processing unit (APU 3.0). The chip is used in budget to mid-range phones including the Motorola Moto G Power 5G 2023, Samsung Galaxy A34, and others.

The memory bandwidth bottleneck in LLM inference occurs because token generation requires reading the entire weight matrix for each generated token. For a 661MB Q4_0 model generating tokens sequentially, each token requires reading approximately 661MB from DRAM. At 15.5 GB/s sustained bandwidth, this limits generation to approximately 23 tokens per second (15.5 GB / 0.661 GB). Actual throughput is slightly lower due to KV cache reads and activation computation overhead.

Power management on ARM mobile processors uses Dynamic Voltage and Frequency Scaling (DVFS). The performance governor locks cores at maximum frequency, while the schedutil governor adjusts frequency based on load. For sustained inference workloads, the performance governor provides consistent throughput. Thermal throttling can reduce frequency when the SoC exceeds thermal limits — typically around 85-95 degrees Celsius for mobile chips. On the Moto G Power, sustained workloads on two A78 cores stay within thermal limits with Android framework stopped.
